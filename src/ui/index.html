        How it works

        This app pretends to be a thermal receipt printer with a cash drawer. Your POS talks to it exactly as it would talk to real hardware, so you can test printing without paper.

        Set it up in the Karbar24 POS

        1. Check the printer is on

          The light on the printer is green and it says Ready.

        2. Add the printer

          In the POS, go to Settings, then Printers & Hardware, and tap New Printer. Fill it in like this:

          Printer nameVirtual printer
          ConnectionNetwork (LAN / Wi-Fi)
          Command languageESC/POS (thermal)
          Target address
          Paper width mm
          Used forCustomer receipts
          SwitchesTurn on Cash drawer, Auto-cut and Print exactly as on screen

        3. Test it

          Save the printer, open it again and tap Test print, then Open drawer. Watch the Printer tab here.

        4. Make a sale

          A cash sale prints the receipt, saves the PDF and opens the drawer, all on its own.

        Good to know

        You close the drawer

        A POS can open a drawer but never closes one. A real drawer is pushed shut by hand, so here you press Close drawer, or set a timer in Settings.

        POS on another device

        In Settings, choose Other devices too, and allow the app if Windows Firewall asks. Both devices need the same network.

        Use the desktop or Android POS

        A web browser cannot send to a network printer, so the web POS opens the normal print window instead.

        Bangla text

        The POS sends Bangla lines as pictures, as it does for a real printer. They appear on the receipt as images, so you can't select them in the PDF.

        How close to real paper

        Line layout, sizes and pictures follow the printer commands. The letter shapes are this computer's font, so they differ a little from a real printer's.

        Test a printer failure

        Turn the printer off with the switch on its front. Your POS gets the same refused connection as with a real printer that is off.

        If something goes wrong

        The POS says it can't reach the printer

        Check the printer here is on and shows Ready. Copy the address from this app again. If the POS is on another device, choose Other devices too in Settings.

        The printer says another app is using the port

        A real printer service or another copy of this tool has that port. Close it, or choose a different port in Settings and use the new address in your POS.

        A receipt warns about wider paper

        Your POS and this app have different paper widths. Set both to the same width, 58 mm or 80 mm.

        Nothing appears when I print

        In your POS, check that this printer is Active and is the default receipt printer, and look at its Print jobs list for a failed job. A browser POS can't reach this app.

        The PDF was not saved

        The receipt shows why. Usually the folder is read-only or the disk is full. Choose another folder in Settings, then press Try saving again.
