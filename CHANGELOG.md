# Changelog

## [Unreleased]

### Added

- Virtual thermal printer on the network (port 9100 by default) that reads ESC/POS commands.
- Live receipt preview and one PDF per receipt, saved to a folder you choose.
- Simulated cash drawer: the POS opens it, you close it or set a timer.
- On-screen guide with the exact values to enter in the Karbar24 POS.
- The guide names the POS switch that makes prints match the screen.
- Test receipt, power switch for testing printer failures, 58 mm and 80 mm paper, light and dark appearance.
- The K24 Virtual Printer logo is the app icon (window, taskbar, Start menu, Desktop, installer) and sits in the header.

### Changed

- New app logo (2026-11-20): the printer with a paper and a blue swirl replaces the thermal receipt printer picture
  everywhere (window, taskbar, Start menu, Desktop, installer, header).
